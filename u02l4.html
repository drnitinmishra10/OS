Introduction

CPU scheduling is the operating system function that decides which ready process receives the CPU next. Efficient scheduling maximizes system performance, improves responsiveness, and ensures fair CPU allocation.

Why Process Scheduling is Required?

  • Efficient CPU utilization.
  • Support multiprogramming.
  • Improve throughput.
  • Reduce waiting time.
  • Provide fairness among processes.
  • Improve response for interactive users.

Scheduling Objectives

ObjectiveDescription
FairnessGive every process a reasonable opportunity to execute.
EfficiencyKeep CPU busy as much as possible.
Fast ResponseReduce response time for interactive applications.
Low WaitingMinimize queue waiting time.
High ThroughputComplete more jobs per unit time.

Types of Schedulers

1. Long-Term Scheduler (Job Scheduler)

  • Selects jobs from secondary storage.
  • Controls degree of multiprogramming.
  • Invoked infrequently.

2. Medium-Term Scheduler

  • Temporarily removes processes from memory.
  • Supports swapping.
  • Reduces memory pressure.

3. Short-Term Scheduler (CPU Scheduler)

  • Selects the next ready process for CPU execution.
  • Runs very frequently.
  • Must be highly efficient.

Comparison of Schedulers

SchedulerFrequencyMain Function
Long-TermLowAdmits jobs into memory.
Medium-TermMediumSwaps processes in/out.
Short-TermVery HighSelects next process for CPU.

Dispatcher

The dispatcher transfers CPU control to the process selected by the short-term scheduler. Its responsibilities include context switching, switching to user mode, and starting execution of the selected process.

Dispatcher Latency: The time required for the dispatcher to stop one process and start another.

Scheduling Criteria

CriterionGoal
CPU UtilizationMaximize CPU usage.
ThroughputMaximize completed processes.
Turnaround TimeMinimize completion time.
Waiting TimeMinimize waiting in ready queue.
Response TimeProvide quick first response.

Real-World Example

Smartphones schedule foreground applications with higher priority than background tasks to provide a smooth user experience while conserving resources.

Key Points

  • Scheduling improves CPU efficiency.
  • Different schedulers perform different tasks.
  • The dispatcher performs CPU handoff.
  • Scheduling criteria are used to compare scheduling algorithms.

MCQs

  5. Which metric should be minimized? Waiting Time
