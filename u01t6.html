Introduction

Different computing environments require different operating systems. A personal laptop, banking server, hospital equipment, mobile phone and spacecraft all have different requirements. Therefore, operating systems are classified into various types depending upon how they manage CPU, memory, users, and resources.

1. Batch Operating System

A Batch Operating System executes similar jobs in batches without user interaction. Jobs are collected and processed one after another automatically.

Working

  • User submits jobs.
  • Jobs are stored in a queue.
  • Operating System executes them sequentially.
  • Results are produced after execution.
Examples
  • Payroll Processing
  • Bank Statement Generation
  • Electricity Bill Generation

Advantages

  • High throughput
  • Efficient for repetitive tasks
  • Reduced manual intervention

Disadvantages

  • No interaction during execution
  • Long turnaround time
  • Difficult debugging

2. Multiprogramming Operating System

Multiple programs are kept in memory simultaneously. Whenever one program waits for I/O, the CPU executes another program.

Advantages

  • Improves CPU utilization
  • Increases system efficiency
  • Reduces CPU idle time

Disadvantages

  • Complex memory management
  • Requires scheduling algorithms
Example:

Suppose Program A is waiting for printer output. Instead of keeping CPU idle, Program B starts executing.

3. Multitasking Operating System

A multitasking operating system allows a single user to execute multiple applications simultaneously.

Example
  • Listening to music
  • Browsing the Internet
  • Editing a document
  • Downloading files

All can happen simultaneously.

Advantages

  • Better productivity
  • Fast response
  • Efficient resource utilization

4. Time-Sharing Operating System

Time-sharing systems allow multiple users to share a computer simultaneously. Each user gets a small time slice (quantum) of CPU.

Examples
  • UNIX
  • Linux Servers
  • Multi-user academic servers

Advantages

  • Quick response time
  • Fair CPU allocation
  • Supports many users

Disadvantages

  • Security concerns
  • Performance decreases with many users

5. Multiprocessing Operating System

A multiprocessing operating system uses two or more CPUs to execute programs simultaneously.

Types

  • Symmetric Multiprocessing (SMP)
  • Asymmetric Multiprocessing (AMP)
Examples
  • Linux
  • Windows Server
  • macOS

6. Distributed Operating System

A Distributed Operating System connects multiple computers and makes them appear as one system.

Features

  • Resource sharing
  • Load balancing
  • Fault tolerance
  • High performance
Applications
  • Cloud Computing
  • Distributed Databases
  • Scientific Computing

7. Network Operating System

A Network Operating System manages network resources and provides communication among computers.

Services

  • File sharing
  • Printer sharing
  • User authentication
  • Remote login
Examples
  • Windows Server
  • Linux Server
  • Novell NetWare

8. Real-Time Operating System (RTOS)

A Real-Time Operating System guarantees response within a specified time limit. Missing deadlines may cause system failure.

Types

Hard Real-Time OS

  • Deadlines must never be missed.
  • Used in aircraft, medical equipment and nuclear systems.

Soft Real-Time OS

  • Occasional deadline misses are acceptable.
  • Used in multimedia and online gaming.
Examples
  • VxWorks
  • QNX
  • RTLinux
  • FreeRTOS

9. Embedded Operating System

Embedded Operating Systems are designed for dedicated devices with limited memory and power.

Applications
  • Smart TVs
  • Microwave ovens
  • ATM Machines
  • Washing Machines
  • IoT Devices

10. Mobile Operating System

A Mobile Operating System is designed for smartphones and tablets.

Examples
  • Android
  • iOS

Features

  • Touch interface
  • Battery optimization
  • Wireless communication
  • Mobile applications
  • Sensor support

Lecture Summary

  • Operating systems are classified according to how they manage resources and users.
  • Batch systems process jobs without user interaction.
  • Multiprogramming improves CPU utilization.
  • Multitasking enables one user to run multiple applications.
  • Time-sharing supports multiple users by allocating CPU time slices.
  • Multiprocessing uses multiple CPUs for better performance.
  • Distributed operating systems integrate multiple computers into a single system.
  • Network operating systems manage shared network resources.
  • Real-time operating systems guarantee timely responses.
  • Embedded and Mobile operating systems are designed for specialized devices.
