Unit 1: Introduction to Operating Systems

Review & Examination Prep - Dr. Nitin Mishra

Core Examination Questions (Long Answer Type)

When preparing for terminal evaluations, ensure you can thoroughly explain and draft architectural breakdowns for the following problems:

Question 1

Differentiate between Monolithic and Microkernel OS structures. Discuss the trade-offs regarding performance and reliability.

Key Elements to Answer:

  • Define where the primary OS services (file systems, device drivers) reside—Kernel Space for Monolithic vs. User Space for Microkernel.
  • Explain the communication mechanism: direct functional call branches versus explicit message passing via Inter-Process Communication (IPC).
  • Address the performance vs. stability trade-off: Monolithic is fast but fragile; Microkernel is highly secure and fault-tolerant but introduces message-switching overhead.
Question 2

What is a System Call? Explain the precise hardware and software sequence that occurs when a user application requests data from a storage drive.

Key Elements to Answer:

  • Define the switch from User Mode (mode bit = 1) to Kernel Mode (mode bit = 0).
  • Explain the role of a trap/software interrupt instruction.
  • Describe how the system indexes into the System Call Vector Table based on an assigned system call number.
Question 3

Distinguish between Hard Real-Time Systems and Soft Real-Time Systems with clear real-world deployment examples.

Key Elements to Answer:

  • Hard Real-Time: Stringent deadlines where missing a time slot equates to a total structural crash (e.g., anti-lock braking systems, flight controls).
  • Soft Real-Time: Prioritized scheduling where missing a deadline causes acceptable performance degradation but not system failure (e.g., digital audio streaming platforms).

Dr. Mishra's Exam Tips

Important Blueprint Tip: Whenever explaining Layered or Microkernel architectures, always draw the architectural layout blocks showing User Space, Kernel Space, and the Hardware layer. In evaluation blueprints, architectural diagrams carry substantial structural weight alongside formal text explanations.
