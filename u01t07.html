Learning Objectives

After completing this lecture, students will be able to:

  • Understand the concept of Operating System Services.
  • Explain the services provided by an Operating System.
  • Describe how OS services simplify user and application interaction.
  • Differentiate between user-oriented and system-oriented services.
  • Understand the practical importance of each OS service.

Introduction

An Operating System (OS) acts as an interface between users, application programs, and computer hardware. Besides managing hardware resources, it provides several essential services that make computing convenient, efficient, and secure.

These services help users execute programs, store files, communicate with devices, share resources, and protect the system from unauthorized access.

Operating System Services

The major services provided by an Operating System are:

  1. User Interface (UI)
  2. Program Execution
  3. I/O Operations
  4. File System Manipulation
  5. Communication
  6. Error Detection
  7. Resource Allocation
  8. Accounting
  9. Protection and Security

1. User Interface (UI)

The User Interface enables users to interact with the computer system.

Types of User Interfaces

Interface Description Examples
Command Line Interface (CLI) Users type commands using a keyboard. Linux Terminal, Windows Command Prompt
Graphical User Interface (GUI) Users interact through icons, windows and menus. Windows, Ubuntu GNOME, macOS
Touch Interface Users interact through touch gestures. Android, iOS
Example:

Opening Microsoft Word by clicking its icon is an example of GUI interaction.

Typing mkdir OS in Linux Terminal is an example of CLI.

2. Program Execution

The Operating System loads a program into memory, starts its execution, manages required resources, and terminates the program after completion.

Steps Involved

  1. Load the program into RAM.
  2. Create a process.
  3. Allocate CPU and memory.
  4. Execute instructions.
  5. Release resources after completion.
Example

When a user double-clicks Google Chrome, the operating system loads Chrome into memory and starts executing it.

3. I/O Operations

Input/Output services allow communication between software and hardware devices.

Input Devices

  • Keyboard
  • Mouse
  • Scanner
  • Microphone

Output Devices

  • Monitor
  • Printer
  • Speaker
  • Projector
Example

When you print a document, the operating system transfers data from memory to the printer using printer drivers.

4. File System Manipulation

The Operating System manages files and directories stored on secondary storage devices.

Functions

  • Create files
  • Delete files
  • Rename files
  • Read and write files
  • Create folders
  • Manage permissions
Example

Saving a Microsoft Word document creates a file on the storage device managed by the operating system.

5. Communication

Communication services allow processes running on the same computer or different computers to exchange data.

Communication Methods

  • Shared Memory
  • Message Passing
  • Network Communication
  • Sockets
  • Pipes
Example

A web browser communicates with a web server using network protocols through the operating system.

6. Error Detection

The operating system continuously monitors the computer system for hardware and software errors.

Errors Detected

  • Memory errors
  • Disk failures
  • Printer errors
  • Network failures
  • CPU exceptions
Example

If a USB drive is removed while copying data, the operating system detects the error and displays a warning.

7. Resource Allocation

The operating system manages and allocates available resources among multiple users and programs.

Resources Managed

  • CPU
  • Main Memory
  • Storage Devices
  • Input Devices
  • Output Devices
  • Network Resources
Example

When several applications are open simultaneously, the operating system schedules CPU time fairly among them.

8. Accounting

Accounting services monitor and record resource usage for performance analysis, billing, and auditing.

Information Recorded

  • CPU usage
  • Memory usage
  • Disk utilization
  • Network usage
  • User login history
Example

Cloud providers record CPU hours used by customers for billing purposes.

9. Protection and Security

Protection and Security services ensure that only authorized users can access system resources.

Security Mechanisms

  • User Authentication
  • Password Protection
  • Access Control
  • Encryption
  • Firewalls
  • Antivirus Protection
Example

A user must enter the correct password or biometric authentication before accessing the operating system.

User-Oriented vs System-Oriented Services

User-Oriented Services System-Oriented Services
User Interface Resource Allocation
Program Execution Accounting
I/O Operations Error Detection
Communication Protection & Security
File Management Performance Monitoring

Summary of Operating System Services

Service Main Purpose
User Interface Allows users to interact with the system.
Program Execution Loads and executes programs.
I/O Operations Controls input and output devices.
File Management Creates and manages files and folders.
Communication Enables process communication.
Error Detection Detects hardware and software errors.
Resource Allocation Distributes system resources efficiently.
Accounting Tracks resource usage.
Protection & Security Protects data and system resources.

Lecture Summary

  • An Operating System provides essential services for users and applications.
  • User Interface enables interaction through CLI, GUI, or touch interfaces.
  • Program Execution manages loading, running, and terminating programs.
  • I/O Operations facilitate communication with hardware devices.
  • File System Manipulation organizes and secures stored data.
  • Communication services support data exchange between processes and systems.
  • Error Detection enhances system reliability.
  • Resource Allocation ensures efficient utilization of CPU, memory, and devices.
  • Accounting tracks resource usage for monitoring and billing.
  • Protection and Security safeguard system resources and user data.
