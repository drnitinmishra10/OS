Round Robin (RR) Scheduling

Round Robin is a preemptive CPU scheduling algorithm in which each process receives the CPU for a fixed amount of time called the time quantum. If the process does not finish within the quantum, it is preempted and placed at the end of the ready queue.

Features

  • Fair CPU allocation.
  • Suitable for time-sharing systems.
  • Good response time.
  • Uses circular ready queue.

Time Quantum

  • Very small quantum → excessive context switching.
  • Very large quantum → behaves like FCFS.
  • An appropriate quantum balances responsiveness and overhead.

Summary

Round Robin scheduling provides fair CPU allocation by assigning each process a fixed time slice. It offers good response time and is widely used in modern multitasking operating systems. Choosing an appropriate time quantum is essential for achieving optimal performance.
