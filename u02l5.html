Shortest Job First (SJF)

The process with the smallest CPU burst executes first. It is a non-preemptive algorithm.

Example: Burst Times: P1=6, P2=2, P3=8, P4=3 Execution Order: P2 → P4 → P1 → P3

Advantages

  • Minimum average waiting time.
  • Efficient for batch systems.

Disadvantages

  • Requires burst time prediction.
  • Long jobs may suffer starvation.

Shortest Remaining Time First (SRTF)

SRTF is the preemptive version of SJF. If a newly arrived process has a shorter remaining burst time, it preempts the running process.

Important: SRTF improves response time but increases context switching.

Key Formulae

  • Turnaround Time = Completion Time − Arrival Time
  • Waiting Time = Turnaround Time − Burst Time

Summary

FCFS is the simplest scheduling algorithm. SJF minimizes average waiting time, while SRTF provides better responsiveness by allowing preemption.

MCQs

  1. FCFS is a Non-Preemptive algorithm.
  2. SRTF is the preemptive version of SJF.
  3. Which algorithm minimizes average waiting time? SJF.
  4. Which algorithm may suffer starvation? SJF/SRTF.
  5. Waiting Time = TAT − Burst Time.
