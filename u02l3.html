Introduction

A thread is the smallest unit of CPU execution. A process may contain one or more threads that share the same memory space while executing independently.

Process vs Thread

ProcessThread
Independent execution unitLightweight execution unit
Own memory spaceShares memory with other threads
High creation overheadLow creation overhead
Slower context switchFaster context switch

Thread States

StateDescription
NewThread created but not started.
RunnableReady for CPU execution.
RunningCurrently executing.
Blocked/WaitingWaiting for I/O or synchronization.
TerminatedExecution completed.

Benefits of Threads

  • Improved responsiveness.
  • Efficient resource sharing.
  • Lower memory consumption.
  • Faster communication.
  • Better CPU utilization.
  • Higher application throughput.

Types of Threads

1. User-Level Threads (ULT)

  • Managed by user-space libraries.
  • Fast creation and switching.
  • Kernel is unaware of individual threads.
  • Blocking system calls may block the entire process.

2. Kernel-Level Threads (KLT)

  • Managed directly by the operating system kernel.
  • Better scheduling support.
  • True parallelism on multicore processors.
  • Higher creation overhead than ULT.

Multithreading

Multithreading allows multiple threads within a single process to execute concurrently, improving performance and responsiveness.

ModelDescription
Many-to-OneMany user threads mapped to one kernel thread.
One-to-OneEach user thread mapped to one kernel thread.
Many-to-ManyMany user threads mapped to many kernel threads.

Applications of Multithreading

  • Web browsers
  • Database servers
  • Multiplayer games
  • Video streaming
  • Web servers
  • Mobile applications

Simple C Example (POSIX Threads)

#include <pthread.h>
void* task(void* arg){
   printf("Hello from thread");
   return NULL;
}
Key Idea: Threads share code, data, and files but maintain separate program counters, stacks, and CPU registers.

Summary

Threads provide lightweight concurrent execution inside a process. They improve application responsiveness, resource utilization, and performance while reducing context-switch overhead compared to processes.
