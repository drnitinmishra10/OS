Lecture Notes by Dr. Nitin Mishra

Generations of Operating Systems

The progression of operating systems is deeply tied to concurrent breakthroughs in underlying hardware technology. We classify this evolution into four distinct generations:

First Generation (1945 – 1955)

Vacuum Tubes and Plugboards

Key Technology: Vacuum Tubes, Plugboards, Paper Tapes.
OS Status: No Operating System.

During this post-war era, electronic digital computers were giant rooms of fragile hardware. Systems were programmed strictly by a single individual setting thousands of physical switches or wiring complex plugboards.

  • All programs were written in absolute machine language.
  • Sign-up sheets were used to reserve time slots; code execution was entirely manual.
  • Core concepts like programming languages, compilers, and system routines did not exist.
Second Generation (1955 – 1965)

Transistors and Batch Systems

Key Technology: Transistors, Magnetic Tapes, Punch Cards.
OS Status: Early Batch Processing (FMS, IBSYS).

The commercial introduction of transistors greatly increased reliability and reduced size. To optimize high setup costs and tackle the "human-in-the-loop" speed bottleneck, the Batch Operating System was introduced.

  • Programmers wrote code on punch cards, which operators collected into physical card groups or "batches."
  • An early control program read batches onto a high-speed magnetic tape, processed them sequentially on a main frame computer (like the IBM 7094), and wrote output onto another tape for off-line printing.
  • Drawback: The CPU sat idle for massive stretches while slow mechanical tape drives read or wrote data.
Third Generation (1965 – 1980)

Integrated Circuits (ICs) and Multiprogramming

Key Technology: Integrated Circuits (ICs), Hard Disks.
OS Status: Multiprogramming and Time-sharing Systems (OS/360, early UNIX).

The dawn of ICs allowed a single computer chip to hold dozens of transistors. This generation fundamentally solved the CPU idle-time dilemma by restructuring system resource scheduling architectures:

  • Multiprogramming: The main memory was partitioned to host multiple active programs simultaneously. When Job A paused to wait for an I/O operation, the CPU immediately switched to process Job B.
  • Spooling (Simultaneous Peripheral Operations On-Line): Direct disk reading allowed jobs to be cached onto disk directly from punch cards as soon as they were dropped off, keeping the job pool dynamic.
  • Time-Sharing: A breakthrough variant where multiple interactive users had terminals attached to a central CPU. The OS provided tiny runtime slices (quanta), switching so quickly that each user felt they had an isolated, private machine.
Fourth Generation (1980 – Present)

Microprocessors and Personal Computing

Key Technology: LSI/VLSI Microprocessors, Personal Computers (PCs), Networks.
OS Status: GUI-based, Network, Distributed, and Mobile Operating Systems.

Large Scale Integration (LSI) condensed thousands of transistors onto a single silicon wafer, birthing the microcomputer era. Computing moved away from massive isolated server hubs straight to individual desks and pockets.

  • Development of rich Graphical User Interfaces (GUIs) like Macintosh and Windows, shifting computing away from command lines.
  • Network & Distributed OS: Computers were no longer isolated; systems gained networking stacks to share files, manage distributed cloud queries, and handle remote logins transparently.
  • Modern Era Shift: Migration into mobile architectures (iOS, Android) and hyper-efficient virtualization backends.
